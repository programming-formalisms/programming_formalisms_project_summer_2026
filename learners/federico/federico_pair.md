What is pair programming?

It is a way of work, where two programmers share the same workstation to write and review code.


How does a good pair behave? Describe what can be observed when pairing online

- They share the whole screen
- They communicate
- They coordinate


When to switch roles? Give a procedure

- The switching could be task based, e.g. one function
- If the task is particularly long, the switch can be based on time
- It can be also based on expertise 


What effects does pair programming have?

- Shares knowledge
- The code is already reviewed
- Other people think differently and can cover more cases
