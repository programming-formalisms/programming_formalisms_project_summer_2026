# Project Formalism

## Research Question
**Temperature rises steadily in the beginning of 20th century until current**.

## Hypothesis

**No change**.

## Methods
 We asses the changes in median temperatures across centuries 1722-till-2022. For each year in century, median temperature in Wnter (10-12- column 2) and summer (6-8- column2) is assesed. We asses the changes across the thwo centuries (1823-1922, 1923-2022) between summer and winter temperatures keeping first century (1722-1822) as reference. The package will run a Kolgomorov-Smirnov two-sided test.

## Results
 
 The package will produce a paired-boxplot that will display the change across reference and comaprison groups with p values and and produce a text file explaining the control, number of samples, degrees of freedom and p-value for the group paired test.

 ## Discussion

 This package is a correlation study and does not account for historical events and industrialization
